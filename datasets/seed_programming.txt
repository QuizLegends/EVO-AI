PROBLEM:
Explain what the following Python function does.

CODE:
def calculate_average(numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

ANALYSIS:
The function receives a collection of numbers.
It checks whether the collection is empty.
If it is empty, it returns zero.
Otherwise, it calculates the sum and divides it by the number of elements.

SOLUTION:
The function calculates the arithmetic mean of a list of numbers.
Its time complexity is O(n), where n is the number of elements.

PROBLEM:
Create a function that checks whether an integer is prime.

SOLUTION:
def is_prime(number):
    if number < 2:
        return False

    for divisor in range(2, int(number ** 0.5) + 1):
        if number % divisor == 0:
            return False

    return True

TESTS:
assert is_prime(2) is True
assert is_prime(7) is True
assert is_prime(9) is False
assert is_prime(1) is False

ANALYSIS:
A prime number has exactly two positive divisors.
Checking divisors up to the square root is sufficient.
The time complexity is O(sqrt(n)).

PROBLEM:
Modify the function to ignore negative numbers without changing the original list.

ORIGINAL CODE:
def calculate_total(numbers):
    return sum(numbers)

SOLUTION:
def calculate_total(numbers):
    return sum(number for number in numbers if number >= 0)

TEST:
values = [-5, 10, 20, -2]
assert calculate_total(values) == 30
assert values == [-5, 10, 20, -2]

ANALYSIS:
The generator expression filters negative values.
The original list remains unchanged.

PROBLEM:
Find the largest number in a list without using max().

SOLUTION:
def find_largest(numbers):
    if not numbers:
        raise ValueError("List cannot be empty")

    largest = numbers[0]

    for number in numbers[1:]:
        if number > largest:
            largest = number

    return largest

TEST:
assert find_largest([4, 9, 2, 15, 7]) == 15

ANALYSIS:
The algorithm visits each element once.
Time complexity: O(n).
Auxiliary space complexity: O(1).

PROBLEM:
Explain the difference between a list and a dictionary.

ANALYSIS:
A list stores ordered elements accessed primarily by position.
A dictionary stores key-value pairs accessed by keys.

EXAMPLE:
users = ["Ana", "Pedro", "Lucas"]

user = {
    "name": "Ana",
    "age": 25
}

A list is useful for sequences of elements.
A dictionary is useful for structured data and key-based lookup.

2. Identify the expected result.
3. Identify the actual result.
4. Inspect the relevant code.
5. Check input types and values.
6. Locate the cause.
7. Propose the smallest appropriate correction.
8. Execute tests after the correction.

IMPORTANT:

Distinguish symptoms from root causes.

TASK: SAFE CODE EXECUTION
LANGUAGE: GENERAL PROGRAMMING
==================================================

PROBLEM:
Explain how an AI programming assistant should execute untrusted code.

SOLUTION:
Untrusted code should run inside an isolated environment.
The environment should have restricted permissions, limited CPU and memory, execution timeouts, and controlled filesystem access.
Network access should be disabled unless explicitly required and authorized.
The execution result should be captured and evaluated separately.

IMPORTANT:
Never execute untrusted code directly on the host environment.
